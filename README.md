# AgriHarvestPriority
---
## 农业工具-优先度与收割
✨ 功能特性

🎯 新增筛选选项
本模组为《缺氧》收获工具（Harvest Tool）增加批量拔除功能，优先级工具增加农业筛选，让植物管理更加高效。

- **批量拔除/取消拔除**: 框选即标记，无需逐个点击（收获工具）
- **优先度-农业过滤** – 独立筛选植物，不与建筑混杂（优先级工具）

---
## Agri-HarvestPriority
✨ Features

🎯 New Filter Options
This mod adds batch uprooting to the Harvest Tool and an Agriculture filter to the Priority Tool, streamlining plant management.

- **Batch Uproot/Cancel Uproot**: Drag to mark or unmark plants without clicking each one (Harvest Tool)
- **Agriculture Filter** – Isolate plants from other buildings when setting priorities (Priority Tool)
